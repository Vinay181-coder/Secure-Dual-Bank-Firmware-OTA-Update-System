# Secure-Dual-Bank-Firmware-OTA-Update-System
An end-to-end Over-the-Air (OTA) firmware update system for the STM32F446RE using AWS IoT Core, AWS IoT Jobs, Amazon S3, and an ESP32-S3 network co-processor. The project features a custom dual-bank bootloader, hardware CRC32 integrity verification, and automatic rollback support for safe and secure remote firmware updates.
